# KYBEZ 2. ročník – podklad pro otázky

Zdroj: [OrgPad KYBEZ 2. ročník](https://orgpad.info/s/cR1vLZAZzZb?embed=true), načtený 6. 10. 2026. Textový export je v `orgpad-KYBEZ-2-rocnik.txt`. Obsahuje nadpisy a text buněk, včetně podstránek. Nezahrnuje přepis textu z obrázků, videí ani externích příloh.

Aktivní sada `data/kyberneticka_bezpecnost_exercises.js` obsahuje 110 redakčně vytvořených otázek v 11 tématech. Pokrývá identity, účty Windows, AD a GPO, autentizační útoky, LAPS, zabezpečení Windows, účty Linuxu, unixová oprávnění, systemd, firewall a základ linuxového systému. Nejde o samostatnou otázku ke každé buňce OrgPadu. Opakované buňky jsou sloučené do vzdělávacích cílů.

Otázky jsou samostatně řešitelné a mají vysvětlené odpovědi. Krátká otevřená vysvětlení používají vlastní kontrolu, protože mohou mít více správných formulací. U příkazů systemd zadání předpokládá existující jednotku `ssh.service`; názvy služeb se mohou mezi distribucemi lišit.

Z podkladu nebyla převzata verze závislá tvrzení o dostupnosti produktů ani historické časové osy. Zjednodušení byla zpřesněna: shadow obsahuje hashe, nikoli vratně zašifrovaná hesla; UFW nemá univerzálně pevný backend; interval LAPS závisí na politice; `enable` a `disable` nemění samy aktuální běh služby; žurnálování nenahrazuje zálohy. Otázky o útocích ověřují principy a obranu.
